# 统一原生子智能体与 Agent Teams 选模

状态：插件和隔离宿主实现已通过下述验收。在尚未接入此接口的官方桌面安装版上，原生行为保持不变。宿主基线：DSH `0.2.2-rc.5`（`9c2670d3`）。

## 开关与范围

- 只复用现有「启用创建路由」（`ui.enabled`）；不新增开关、不新增配置字段、不写宿主全局默认值。其他版本没有所需接口时须明确报告原生接入不可用，保留既有行为，不显示为已接管。
- 开启且宿主支持时，`subagent`、Agent Teams 的新成员创建以及兼容入口 `routed_subagent` 使用当前预设的同一套档案。Team 复用 `subagent` 和 `subagent_fork`，所以要覆盖完整的团队创建，不能只改 spawn 而忽略 fork。Team 开关不影响普通 `subagent` 的选模。
- 关闭后原生创建按 DSH 规则执行。开关或预设变更不触发委派，不切换主模型或已创建成员的模型，也不改变 Team 任务、消息、成员身份、fork 的上下文继承或权限。
- 运行时只读取当前预设；共享草稿池不参与。启用且选中档案不可执行时明确报错，不退回父模型或换档案。

## 选择规则

1. 未指定任何路由字段：使用默认档案的完整 `provider/model/effort`。
2. 明确档案 ID：精确匹配该档案。原生旧调用显式给出完整模型和档位时，精确匹配预设中唯一的完整档案；只给 provider + model 且匹配唯一时，使用该档案的档位；零个或多个都拒绝，不猜测。候选说明仅供主 Agent 判断，不自动分类或启用额外的推理调用。
3. 档案的档位须被宿主与当前 Session 授权，或明确无档位；原生的省略档位规则不能替代档案档位。取消、拒绝、元数据不可用、配置代际变化都不能自动重放创建。

## 宿主接入

- [Agent Teams 指令与工具注册](https://github.com/deepseek-ai/deepseek-harness/blob/9c2670d3bce5275e0d1610272958121af87787bb/packages/team/tool-agent-team/src/index.ts#L23-L33) 显式复用普通子智能体工具；不是另一个工具或任务看板触发创建。 [原生工具](https://github.com/deepseek-ai/deepseek-harness/blob/9c2670d3bce5275e0d1610272958121af87787bb/packages/subagent/tool-subagent/src/index.ts#L274-L332) 先解析选模、授权和预检，再提交启动；自定义模型最终仍由原生创建流程校验。内置 fork 没有向模型公开显式选模字段，不能靠向旧 schema 塞参数来覆盖。
- 在宿主为可选模的新建路径新增正式解析接口：传入准确的父 Agent、原生入口、调用身份、原始选择和取消信号，插件只返回固定模型档案和策略代际，不启动、不代理执行。宿主让策略与批准检查依据最终选中的路由，保留原生 Session 授权、取消、深度和容量限制。fork 可提供经过同样检查的档案选择，但跨模型可能失去提供方的会话前缀缓存复用；这是性能差异，不得改变 fork 的上下文语义。
- 不改安装包，不使用参数突变、同名工具覆盖或捕获后再创建。现有 `tools/pre-execute` 负责允许、拒绝或审批，不是受支持的参数转换接口；`agentOptions` 只支持静态默认，不是动态预设。
- `routed_subagent` 内部派发走同一宿主授权链，复用已选档案并关联原调用，只产生一笔决策、一次创建。审计区分入口、默认/显式、档案 ID、策略版本、原生创建回执及实际子请求；不要用界面标签或创建回执当请求证据。
- 新版可读既有审计；有原生入口记录的日志包含旧版不认识的字段。不要直接让旧版接管该日志：若要降级，先核对并结清未决项，再备份原日志与配置，按旧版格式恢复。不得改写或删除记录来清除暂停状态。

## 验收

| 场景 | 必须观察到的结果 |
| --- | --- |
| Team 开启、关闭各建一个原生子智能体 | 在相同插件预设下，真实请求路由一致，Team 的任务与消息能力保持原样 |
| Team 中通过 fork 创建 | 真实请求命中相同策略；仍继承完成轮次，不改成员身份或消息能力 |
| 切换到默认模型、档位都不同的预设后再建 | 不传模型的原生调用从 A 跟随到 B；原子会话及主会话请求不变 |
| 显式档案、唯一模型、歧义、未授权、取消 | 前两项实际路由等于档案；后三项无子会话创建，不尝试其他模型 |
| 关闭现有开关、旧宿主没有接口、兼容入口 | 分别验证恢复旧原生行为、显示能力缺口、已有路由不回归且双重入口不重复创建 |
